# Vibe Deck 操作ガイド — Cursor 編

対象プロファイル: **Vibe · Cursor**（テーマ色: ダークIDE＋青）
対象アプリ: Cursor.app

## 1. 画面の見かた

### 上段5キー = エージェントレーン（全ページ共通）

Cursor のエージェントセッション最大5つの状態が色で並びます（transcript の書き出しタイミングに依存するため、反映は他ツールよりわずかに遅れることがあります）。

| 色 | 意味 | あなたがやること |
|----|------|------------------|
| 白 Idle | 待機中 | 指示を出す（New / Skills） |
| 青 Thinking | 作業中 | 待つ（止めたければ Stop） |
| 緑 Done | **編集完了（変更が保留中）** | Diff で確認 → Accept / Reject |
| 橙 Input | 承認・入力待ち | Accept / Reject |
| 赤 Error | エラー | レーンを押して画面確認 |
| 灰 Ready | 空きレーン | 押すと Cursor を前面化 |

3段目右端の細長い表示は本体の小窓ウィジェット（時計）で、キーではありません。**ページ移動は下段の物理ボタン左右**です。

## 2. Page 1 — CONTROL（このキーで実際に起きること）

| キー | 表示 | Cursor での実動作 |
|------|------|-------------------|
| 中段1 | Accept | Return 送信（承認/Run。**橙または緑で発火**。緑のときは「変更をすべて受け入れる」動きに相当） |
| 中段2 | Reject | ⌘⌫ 送信（**Reject all＝変更をすべて棄却**。橙または緑で発火） |
| 中段3 | Stop | ⌘⇧⌫ 送信（ターン中断。青/橙のときだけ発火） |
| 中段4 | Diff | ⌘E（Changes / Agent レイアウトを開く） |
| 中段5 | New | ⌘N（新規チャット） |
| 下段1 | Voice | ⌘⇧Space（音声入力） |
| 下段2 | Terminal | ⌃`（ターミナル開閉） |
| 下段3 | Mode | ⌘.（Agent / Ask モードメニュー） |

どのキーも押すと**自動で Cursor.app を前面化→前面確認→送出**します。

**Cursor 固有の注意**:
- **Cursor だけは緑（Done）でも Accept / Reject が有効**です。エージェントの編集完了後、Diff で確認して Accept（全部通す）か Reject（⌘⌫で全部戻す）を手元で選べます。
- **MCP 承認の既知問題**: 承認ダイアログのフォーカスがずれていると Return 単体で効かないことがあります（Cursor 公式の既知問題）。効かなかったら本体キーボードで Tab → もう一度デッキの Accept を押してください。
- Reject（⌘⌫）は「Reject all」です。一部だけ棄却したい場合は Diff を開いて画面上で個別に操作してください。

## 3. Page 2 — SKILLS（定型プロンプト8）

押すとチャット入力欄にプロンプト冒頭が入力されます（**送信はされません**。続きを書いて Return）。

中段: Plan / Implement / Review / Fix / Test
下段: Explain / Commit / Summary

コードを選択してから Skills を押すと、選択範囲を文脈にした指示が出しやすくなります（選択を明示的に渡すなら Page 3 の Context）。

## 4. Page 3 — SYSTEM

共通行（中段）: Focus（Cursor を前面化）/ Refresh（状態色の再取得）/ Settings（⌘,）/ Help（⇧⌘P コマンドパレット）/ **Model（⌘/ モデル切替）**

**Cursor 固有ゾーン（下段3キー）**:

| キー | 動作 |
|------|------|
| Composer | ⌘I（Composer / エージェントパネル） |
| Context | ⇧⌘L（選択中のコードをチャットの文脈に追加） |
| Inline | ⌘K（インライン編集＝カーソル位置・選択範囲の局所修正） |

## 5. ダイヤル（全ページ共通）

| ダイヤル | 回転 | 押し込み |
|----------|------|----------|
| 左 | ツール切替（回し終えて約1秒後に Studio が自動再起動。復帰まで約9秒・数秒消灯します） | Cursor を前面化 |
| 中 | レーン選択（選択レーンが点滅し、セッション名が通知に出る） | Cursor を前面化 |
| 右 | 自律軸: どちらに回しても ⌘/（モデルメニューを開く） | Mode（⌘.） |

## 6. おすすめワークフロー

1. エディタでコードを選択 → Context（⇧⌘L）→ 指示。小さな修正なら Inline（⌘K）
2. 青 → 放置
3. **橙 → Accept / Reject**（効かなければ Tab → Accept）
4. **緑 → Diff で差分確認 → Accept（全部通す）or Reject（全部戻す）**
5. 承認が多すぎる → Cursor 側の Auto-review / allowlist 設定を緩めるのが本筋

## 7. 困ったとき

- **キーが効かない（初回）**: システム設定 → プライバシーとセキュリティ → オートメーション で Ulanzi Studio → System Events を許可
- **Accept が効かない（橙）**: MCP 承認のフォーカス問題の可能性。Tab → Accept
- **Accept を押しても何も起きない（白/青）**: ガードが送出を止めています（正常）。`~/Library/Logs/vibe-deck-plugin.log` に `guard blocked` とあれば仕様どおり
- **色の反映が遅い**: Cursor の transcript 書き出し待ちです。Page 3 の Refresh で再取得できます
