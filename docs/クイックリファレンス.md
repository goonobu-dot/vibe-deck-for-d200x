# Vibe Deck クイックリファレンス（統一レイアウト / Vibe Deck OS）

**3ツール共通**: どのプロファイル（Claude Code / Codex / Cursor）でも、同じ位置のキーは同じ意味。
ツールの見分けは背景テーマ色のみ（紫=Claude / 黒ティール=Codex / 青=Cursor）。

## 色＋ラベル（English only）

| 色 | ラベル | 状態 |
|----|--------|------|
| 白 | Idle | idle |
| 青 | Thinking | thinking |
| 緑 | Done | done |
| 橙 | Input | needs_input |
| 赤 | Error | error |
| 灰 | Ready | 未使用レーン（押すとアプリ前面化） |

## 全ページ共通・上段 = エージェントレーン

| 上段 | 機能 |
|------|------|
| L1〜L5 | 現ツールの並列セッション slot 1〜5 の状態色。押すとアプリ前面化 |

上段はページを切り替えても常に表示され、監視が途切れない。

## Page 1 — CONTROL

| 中段 | 機能 | | 下段 | 機能 |
|------|------|-|------|------|
| 1 | **Accept**（承認/Run） | | 1 | **Voice**（音声入力） |
| 2 | **Reject**（否認） | | 2 | **Terminal**（⌃`） |
| 3 | **Stop**（中断） | | 3 | **Mode**（自律度/権限UI） |
| 4 | **Diff**（差分） | | 右端 | 小窓バー（時計。キーなし） |
| 5 | **New**（新規チャット） | | | |

ページ移動は下段の**物理ボタン左右**で。

**安全機構（誤爆防止）**: Accept / Reject は橙（Input）のとき以外は送出されない
（Cursor のみ緑 Done でも有効=変更の一括承認/棄却）。Stop は 青/橙 のときのみ有効。
全キーが「自動で対象アプリを前面化→前面確認→送出」するため、先に Focus を押す必要はない。

## Page 2 — SKILLS（全ツール同一の定型プロンプト8）

中段: **Plan · Implement · Review · Fix · Test**
下段: **Explain · Commit · Summary**

押すとプロンプト冒頭がチャットに入力される（送信はしない。続きを書いて Enter）。

## Page 3 — SYSTEM

中段: **Focus / Refresh / Settings / Help / Model**（Model はツール別メニュー: Claude ⇧⌘I / Codex ⇧⌘P / Cursor ⌘/）
下段（唯一ツールで変わる隔離ゾーン・3キー）:

| Claude Code | Codex | Cursor |
|-------------|-------|--------|
| Browser ⇧⌘B | Plan（/plan） | Composer ⌘I |
| SideChat ⌘; | Fast（/fast） | Context ⇧⌘L |
| Effort ⇧⌘E | Quick ⌘⌥N | Inline ⌘K |

## ダイヤル（全ページ共通）

| ダイヤル | 回転 | 押し込み |
|----------|------|----------|
| 左 | **ツール切替**（Claude↔Codex↔Cursor の3プロファイル巡回。回し終えて約1秒後に Studio が自動再起動して切替わる＝復帰まで約9秒） | 現ツールを前面化 |
| 中 | **レーン選択**（選択レーンが点滅＋セッション名を通知表示） | 選択ツールを前面化 |
| 右 | **自律軸**（左=速く / 右=深く。Claude=Effort、Codex=/fast⇔/plan、Cursor=モデル） | Mode UI を開く |

## 既知の限界

1. **verb キーの初回**: macOS の「オートメーション（System Events）」許可ダイアログが出たら Ulanzi Studio を許可すること。未許可だと Accept 等が送出されない。
2. **Claude の Voice（⇪）**: macOS の仕様上デッキからは不安定（既知・据え置き）。
3. **Codex verb**: ChatGPT デスクトップアプリ前提。
4. **bridge 停止時**: 安全側に倒し Accept/Reject/Stop は送出されない（他 verb は動く）。
5. **ツール切替は Studio 自動再起動方式**: Ulanzi Studio にはプロファイル切替の外部APIが存在しない（WS・UIスクリプト両方とも不可を実機検証済み）。そのため設定書換→Studio 自動再起動で実現しており、切替に約9秒かかる。切替中はデッキが数秒消灯する。
