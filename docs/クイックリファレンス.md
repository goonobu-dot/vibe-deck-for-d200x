# Vibe Deck クイックリファレンス（統一レイアウト / Vibe Deck OS）

**3ツール共通**: どのプロファイル（Claude Code / Codex / Cursor）でも、同じ位置のキーは同じ意味。
ツールの見分けは背景テーマ色のみ（紫=Claude / 黒ティール=Codex / 青=Cursor）。

## 色＋ラベル（English only）

| 色 | ラベル | 状態 | 補足 |
|----|--------|------|------|
| 白 | IDLE | idle | 待機中 |
| 青 | THINK | thinking | 作業中（呼吸アニメ。15分超で呼吸が約2倍速の長考アラート） |
| 緑 | DONE | done | 完了直後（白チェックがポップ） |
| 深緑 | DONE | done_old | **未確認の完了**（90秒後から最大30分保持。レーン押下で既読=白へ） |
| 橙 | INPUT | needs_input | 承認・入力待ち（点滅。カードに承認内容を表示） |
| 赤 | ERROR | error | エラー |
| 灰 | READY | empty | 未使用レーン（押すとアプリ前面化） |
| 濃灰 | OFFLINE | offline | bridge 不達（3回連続失敗で全レーン表示・自動復帰） |

## 全ページ共通・上段 = エージェントレーン（動的カード）

| 上段 | 機能 |
|------|------|
| L1〜L5 | 現ツールの並列セッション slot 1〜5 の全面1色カード（状態色＋白抜き文字）。表示内容=状態ラベル・経過時間・セッション名・橙時は承認内容（例 `Bash: git push`）。押すと既読化＋フォーカス |

- カードの名前: Claude Code=セッションタイトル / Codex=スレッド名（無名なら開始日時 `7/31 10:19`）/ Cursor=プロジェクトフォルダ名
- レーン押下: 完了レーンは既読（白）に戻り、ツールにフォーカス。Cursor は `cursor://` ディープリンクで該当プロジェクトのウィンドウへ直接ジャンプ（パス復号失敗時・Claude/Codex はアプリ前面化）
- 起動時は左から順に点灯。上段はページを切り替えても常に表示され、監視が途切れない。

## Page 1 — CONTROL

| 中段 | 機能 | | 下段 | 機能 |
|------|------|-|------|------|
| 1 | **Accept**（承認/Run） | | 1 | **Voice**（音声入力） |
| 2 | **Reject**（否認） | | 2 | **Terminal**（⌃`） |
| 3 | **Stop**（中断） | | 3 | **Mode**（自律度/権限UI） |
| 4 | **Diff**（差分） | | 右端 | 小窓バー（時計。キーなし） |
| 5 | **New**（新規チャット） | | | |

ページ移動は下段の**物理ボタン左右**で。

**安全機構（誤爆防止）**: Accept / Reject は橙（Input）のとき以外は送出されない
（Cursor のみ緑 Done でも有効=変更の一括承認/棄却）。Stop は 青/橙 のときのみ有効。
ガードに阻止された押下は送出されず、**警告音＋押したキーの赤フラッシュ**で知らせる。
橙のレーンがある間は **Accept キー自体がオレンジ点滅（Armed）** し、押すべきキーが一目でわかる。
全キーが「自動で対象アプリを前面化→前面確認→送出」するため、先にアプリを前面化しておく必要はない。

## ダイヤル（全ページ共通・Studio標準ホットキー方式）

※Studio はダイヤル1操作にホットキー1つしか割り当てられない（プラグイン配信も不可）ため、「開く→選ぶ→確定」はダイヤル単体では不可能。そこで**キーでメニューを開き → 右ダイヤルで選び → 押して確定**という分担にしています。**ツール切替は Page 3 の Tool キー**（押すたび次のツールへ・約9秒）。

| ダイヤル | 回転 | 押し込み |
|----------|------|----------|
| 左 | **スクロール**（左=下 / 右=上） | **Effort/モデルのメニューを開く**（Claude ⇧⌘E・Codex ⇧⌘P・Cursor ⌘/） |
| 中 | **セッション/チャット移動**（Claude ⌃⇧Tab/⌃Tab・Cursor ⌘[/⌘]・Codex ⌘[/⌘]） | **Mode メニューを開く**（Claude ⇧⌘M・Cursor ⌘.・Codex は ⌘G 過去チャット検索） |
| 右 | **メニュー選択ジョグ**（開いているメニューを ↑/↓ で移動） | **Return（選択を確定）** |

## ブリッジ

```bash
curl http://127.0.0.1:17823/health
curl 'http://127.0.0.1:17823/status?tool=cursor'
curl 'http://127.0.0.1:17823/event?tool=claude&state=needs_input&session=<id>'  # hooks からの状態通知
open http://127.0.0.1:17823/dashboard   # Web ダッシュボード（同一Mac内・全ツールのレーンをライブ表示）
node scripts/wire-deck.mjs   # 配線（再実行可・冪等）
```

**承認フロー（Claude Code hooks 連携）**: `~/.claude/settings.json` の hooks に
`scripts/claude-hooks/vibe-deck-event.sh` を Notification（引数 `needs_input`）と Stop（引数 `done`）で登録すると、
承認要求の瞬間に確実に橙になる（JSON スニペットは取扱説明書 §7 参照。hooks は新規セッションから有効）。

## 既知の限界

1. **verb キーの初回**: macOS の「オートメーション（System Events）」許可ダイアログが出たら Ulanzi Studio を許可すること。未許可だと Accept 等が送出されない。
2. **Claude の Voice（⇪）**: macOS の仕様上デッキからは不安定（既知・据え置き）。
3. **Codex verb**: ChatGPT デスクトップアプリ前提。
4. **bridge 停止時**: 安全側に倒し Accept/Reject/Stop は送出されない（他 verb は動く）。
5. **ツール切替は Studio 自動再起動方式**: Ulanzi Studio にはプロファイル切替の外部APIが存在しない（WS・UIスクリプト両方とも不可を実機検証済み）。そのため設定書換→Studio 自動再起動で実現しており、切替に約9秒かかる。切替中はデッキが数秒消灯する。
