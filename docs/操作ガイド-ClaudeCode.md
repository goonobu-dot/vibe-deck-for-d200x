# Vibe Deck 操作ガイド — Claude Code 編

対象プロファイル: **Vibe · Claude Code**（テーマ色: 深紫＋オレンジ）
対象アプリ: Claude.app（デスクトップ。CLI セッションも状態監視の対象）

## 1. 画面の見かた

### 上段5キー = エージェントレーン（全ページ共通・動的カード）

Claude Code の並列セッション最大5つが**全面1色のカード**（状態色＋白抜き文字）で並びます。CLI・デスクトップ両方のセッションを検知します。カードには**状態ラベル・経過時間・セッション名（＝カードの名前はセッションタイトル）**、橙のときは**承認内容**（例 `Bash: git push`）が表示されます。起動時は左から順に点灯します。

| 色 | 意味 | あなたがやること |
|----|------|------------------|
| 白 Idle | 待機中 | 指示を出す（New / Skills） |
| 青 Thinking | 作業中（呼吸アニメ。15分超で呼吸が約2倍速の長考アラート） | 待つ（止めたければ Stop） |
| 緑 Done | ターン完了直後（白チェックがポップ） | Diff で確認 → 次の指示 |
| 深緑 Done | **未確認の完了**（90秒後から最大30分保持） | レーンを押して既読に（白へ戻る） |
| 橙 Input | **承認・入力待ち**（カード点滅・Accept キーもオレンジ点滅） | Accept / Reject |
| 赤 Error | エラー | レーンを押して画面確認 |
| 灰 Ready | 空きレーン | 押すと Claude を前面化 |
| 濃灰 OFFLINE | bridge 不達（3回連続失敗で全レーン表示・自動復帰） | ブリッジを確認 |

レーンを押すと**既読化＋ Claude.app の前面化**が行われます。3段目右端の細長い表示は本体の小窓ウィジェット（時計）で、キーではありません。**ページ移動は下段の物理ボタン左右**です。

## 2. Page 1 — CONTROL（このキーで実際に起きること）

| キー | 表示 | Claude Code での実動作 |
|------|------|------------------------|
| 中段1 | Accept | Return 送信（承認/実行。**橙のときだけ発火**） |
| 中段2 | Reject | Esc 送信（否認。**橙のときだけ発火**） |
| 中段3 | Stop | Esc 送信（ターン中断。青/橙のときだけ発火） |
| 中段4 | Diff | ⇧⌘D（差分ビューを開く） |
| 中段5 | New | ⌘N（新規チャット） |
| 下段1 | Voice | ⇪（音声入力。環境により不安定 → 効かない場合は本体キーボードで） |
| 下段2 | Terminal | ⌃`（ターミナル開閉） |
| 下段3 | Mode | ⇧⌘M（Permission モード切替UI） |

どのキーも押すと**自動で Claude.app を前面化→前面確認→送出**します。先にアプリを前面化しておく必要はありません。

**Claude 固有の注意**: Claude には公式に「否認専用キー」がなく、Reject と Stop はどちらも Esc です。橙で押せば否認、青で押せば中断、と**状態側で意味が決まります**。ガードがあるので取り違えても安全側に倒れます。承認回数自体を減らしたいときは Mode（⇧⌘M）で Permission を緩めるのが本筋です。

**承認フロー（hooks 連携）**: Claude Code の Notification / Stop フックを bridge の `/event` に登録しておくと、**承認要求の瞬間に確実にレーンが橙**になります。橙の間は **Accept キー自体がオレンジ点滅（Armed）**。Accept=承認（「一度だけ許可」等、ダイアログの既定を確定）/ Reject=拒否 / Stop=中断です。設定方法（`~/.claude/settings.json` の JSON スニペット）は取扱説明書 §7 を参照してください。hooks は新規セッションから有効です。

**ガードフィードバック**: 橙以外で Accept / Reject を押しても（Stop は青/橙以外）送出されず、**警告音＋押したキーの赤フラッシュ**で知らせます。

## 3. Page 2 — SKILLS（定型プロンプト8）

押すとチャット入力欄にプロンプト冒頭が入力されます（**送信はされません**。続きを書いて Return）。

中段: Plan / Implement / Review / Fix / Test
下段: Explain / Commit / Summary

例: どのレーンも白のとき → New → Skills の「Fix」→ エラー内容を貼って Return。

## 4. Page 3 — SYSTEM

共通行（中段）: Tool（押すたびツール切替）/ Refresh（状態色の再取得）/ Settings（⌘,）/ Help（⌘/）/ **Model（押すたびモデルを1つ切替**＝⇧⌘I→次候補→確定のマクロ。Fable→Opus→…と巡回**）**

**Claude 固有ゾーン（下段3キー）**:

| キー | 動作 |
|------|------|
| Browser | ⇧⌘B（並走ブラウザペイン。動作確認やドキュメント参照に） |
| SideChat | ⌘;（本筋を止めずに横質問） |
| Effort | **押すたびエフォートを1段切替**（⇧⌘E→次候補→確定のマクロ） |

## 4.5 Page 4 — COMMANDS（自走コマンド）

中段の5キーは全ツール共通の「自走プロンプト」です。押すと入力欄に文が入ります（**送信はされません**。Goal は続きにゴールを書いて Return、他は必要なら補足してから Return）。

| キー | 動作 |
|------|------|
| Goal | 「ゴール: 次の状態になるまで自走で完了させてください → 」を入力（続きにゴール条件を書く） |
| Continue | 「続きを完了まで進めてください。途中で止まらず、詰まったら状況を報告してください。」を入力 |
| FixAll | 「残っているエラー・警告・テスト失敗をすべて修正してください。」を入力 |
| TestAll | 「テストを追加・実行し、全部通るまで修正を繰り返してください。」を入力 |
| Ship | 「変更をセルフレビューして、コミットメッセージを付けてコミットまで仕上げてください。」を入力 |

**Claude 固有ゾーン（下段3キー）**:

| キー | 動作 |
|------|------|
| Compact | `/compact` を入力して実行（コンテキストを圧縮して長時間セッションを続ける） |
| Session | ⌃Tab（次のセッションへ切替） |
| PickEl | ⇧⌘S（画面要素のピック） |

## 5. ダイヤル（全ページ共通）

| ダイヤル | 回転 | 押し込み |
|----------|------|----------|
| 左 | スクロール（左=下 / 右=上） | — |
| 中 | セッション切替（左=⌃⇧Tab 前へ / 右=⌃Tab 次へ） | — |
| 右 | **メニュー選択ジョグ**（開いているメニュー内を ↑/↓ で移動） | **Return（確定）** |

**ダイヤルだけで切り替える手順**: 左ダイヤルを押す（Effort/モデルのメニューが開く）または中ダイヤルを押す（Mode メニュー） → 右ダイヤルを回して選ぶ → 右ダイヤルを押して確定。
※ダイヤルのキーは**前面のアプリ**に送られます。効かないときは対象アプリ（Claude/ChatGPT/Cursor）が前面か確認してください。


**メニューの切替手順**: Page 1 の Mode キー（または Page 3 の Effort / Model キー）でメニューを開く → 右ダイヤルを回して選ぶ → 右ダイヤルを押して確定。Effort / Model キーは単独でも「押すたび1段切替」します。

**ツール切替は Page 3 の Tool キー**です。押すたび Claude→Codex→Cursor と巡回し、約1秒後に Studio が自動再起動して切り替わります（復帰まで約9秒・数秒消灯しますが正常です）。

## 6. おすすめワークフロー

1. 白 → New または Skills で指示
2. 青 → 放置（並列で別レーンに指示してもよい）
3. **橙 → デッキを見て Accept / Reject**（画面を見なくても手元で完結）
4. 緑 → Diff で差分確認 → Skills「Commit」
5. 承認が多すぎる → Mode で Permission を Accept edits / Auto に

## 7. 困ったとき

- **キーが効かない（初回）**: システム設定 → プライバシーとセキュリティ → オートメーション で Ulanzi Studio → System Events を許可
- **Accept を押したら警告音が鳴ってキーが赤くフラッシュした**: 正常です（橙以外ではガードが送出を止め、音とフラッシュで知らせます）。ログ `~/Library/Logs/vibe-deck-plugin.log` に `guard blocked` と出ていれば仕様どおり
- **色が更新されない**: Page 3 の Refresh → それでもダメなら `curl http://127.0.0.1:17823/health`。ブラウザで `http://127.0.0.1:17823/dashboard` を開くと bridge が見ている状態をそのまま確認できます
- **承認してもすぐ橙にならない／橙が遅い**: hooks（Notification / Stop）が未登録の可能性。取扱説明書 §7 の JSON を `~/.claude/settings.json` に登録してください（新規セッションから有効）
- **Voice（⇪）が効かない**: 既知の制約です。Claude 側の音声入力設定を確認するか、本体キーボードの ⇪ を使ってください
