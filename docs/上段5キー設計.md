## Goal

バイブコーディング中に「今の状態」が見え、承認／否認／停止／復帰を手元で素早く行える。

**発想の核:** Accept ≠ 編集の Accept。Accept = **いま出ている承認（Run）を通す**。

## Tool mapping（プロファイルに追従）

| Profile | Accept (Run) | Reject | Stop | Focus app |
|---------|--------------|--------|------|-----------|
| Vibe · Cursor | Enter | ⌘⌫（Reject all） | ⌘⇧⌫ | Cursor.app |
| Codex_D200X | `a`（Accept once） | `d`（Decline） | Esc | ChatGPT.app |
| Vibe · Claude Code | Enter | Esc | Esc | Claude.app |

### なぜこの割り当てか

- **Cursor:** 公式どおり Enter=承認（フォーカス時）/ ⌘⌫=Reject all / ⌘⇧⌫=Cancel。MCP 承認はフォーカスがズレることがあり、**Tab → Accept** が必要な場合あり。
- **Codex:** 承認オーバーレイは `[a] Accept once` / `[d] Decline`（「一度だけ許可」＝`a`）。Stop は Esc。Reject と Stop を分離。
- **Claude:** Enter=送信/承認、Esc=停止/ダイアログ閉じ。Reject と Stop は同じ Esc（状態で意味が分かれる）。

Page 2 Skills は `system.text` でプロンプトを直接入力（`.sh` を open しない）。
