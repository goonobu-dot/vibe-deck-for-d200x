## 推奨ワークフロー

1. **計画** — Codex `/plan` または Claude/Cursor で方針を固める  
2. **実装** — Cursor は選択→⇧⌘L→指示、または ⌘K で局所修正  
3. **橙** — Focus → Accept / Reject  
4. **緑** — Diff で確認 → 必要なら Reject all  
5. **並列** — Claude Browser / Terminal、Codex Review、Cursor Changes

承認が多すぎるときは、デッキより先に各ツールの **Permission / Auto-review** を緩める方が効く。
