# Vibe Deck 操作ガイド — Codex 編

対象プロファイル: **Codex_D200X**（テーマ色: 黒＋ティール）
対象アプリ: **ChatGPT.app（デスクトップ）** — Codex の操作キーはデスクトップアプリ前提です

## 1. 画面の見かた

### 上段5キー = エージェントレーン（全ページ共通）

Codex エージェント最大5つの状態が色で並びます。

| 色 | 意味 | あなたがやること |
|----|------|------------------|
| 白 Idle | 待機中 | 指示を出す（New / Skills） |
| 青 Thinking | 作業中 | 待つ（止めたければ Stop） |
| 緑 Done | ターン完了 | Diff（Review）で確認 |
| 橙 Input | **承認待ちオーバーレイ表示中** | Accept / Reject |
| 赤 Error | エラー | レーンを押して画面確認 |
| 灰 Ready | 空きレーン | 押すと ChatGPT を前面化 |

3段目右端の細長い表示は本体の小窓ウィジェット（時計）で、キーではありません。**ページ移動は下段の物理ボタン左右**です。

## 2. Page 1 — CONTROL（このキーで実際に起きること）

| キー | 表示 | Codex での実動作 |
|------|------|------------------|
| 中段1 | Accept | `a` 送信（**Accept once＝一度だけ許可**。橙のときだけ発火） |
| 中段2 | Reject | `d` 送信（**Decline＝否認**。橙のときだけ発火） |
| 中段3 | Stop | Esc 送信（ターン中断。青/橙のときだけ発火） |
| 中段4 | Diff | ⌘⌥B（Review パネルの開閉） |
| 中段5 | New | ⌘N（新規チャット） |
| 下段1 | Voice | ⌃⇧D（音声入力） |
| 下段2 | Terminal | ⌃`（ターミナル開閉） |
| 下段3 | Mode | チャット欄に `/permissions` を入力して実行（権限設定を開く） |

どのキーも押すと**自動で ChatGPT.app を前面化→前面確認→送出**します。

**Codex 固有の注意**:
- `a` / `d` は**承認オーバーレイが表示されている間だけ**意味を持つキーです。それ以外のタイミングだと文字入力になってしまうため、デッキ側のガードが「橙のときだけ送出」に制限しています。これが誤爆防止の要です。
- Accept は「一度だけ許可」です。セッション全体を許可したい場合は画面上で `s`（session）を選ぶか、Mode（/permissions）で恒久設定を変えてください。
- Mode キーはチャット入力欄にフォーカスがある状態で効きます（自動前面化後、入力欄が選ばれていない場合は一度クリックが必要なことがあります）。

## 3. Page 2 — SKILLS（定型プロンプト8）

押すとチャット入力欄にプロンプト冒頭が入力されます（**送信はされません**。続きを書いて Return）。

中段: Plan / Implement / Review / Fix / Test
下段: Explain / Commit / Summary

## 4. Page 3 — SYSTEM

共通行（中段）: Focus（ChatGPT を前面化）/ Refresh（状態色の再取得）/ Settings（⌘,）/ Help（⇧⌘/）/ **Model（⇧⌘P コマンドメニュー）**

**Codex 固有ゾーン（下段3キー）**:

| キー | 動作 |
|------|------|
| Plan | `/plan` を入力して実行（計画モード＝深く考えてから着手） |
| Fast | `/fast` を入力して実行（高速モード＝軽いタスク向け） |
| Quick | ⌘⌥N（クイックチャット） |

## 5. ダイヤル（全ページ共通）

| ダイヤル | 回転 | 押し込み |
|----------|------|----------|
| 左 | ツール切替（回し終えて約1秒後に Studio が自動再起動。復帰まで約9秒・数秒消灯します） | ChatGPT を前面化 |
| 中 | レーン選択（選択レーンが点滅し、セッション名が通知に出る） | ChatGPT を前面化 |
| 右 | 自律軸: **左に回す=/fast（速く）・右に回す=/plan（深く）** | Mode（/permissions） |

右ダイヤルは Codex Micro の「reasoning effort ダイヤル」に相当します。回すとチャット欄にコマンドが入力・実行されるため、チャット入力欄が使える状態で操作してください。

## 6. おすすめワークフロー

1. 白 → Skills「Plan」で計画 → 内容を確認して実装指示
2. 青 → 放置。急ぎなら右ダイヤル左回し（/fast）
3. **橙 → Accept（一度だけ許可）/ Reject**
4. 緑 → Diff（Review パネル）で差分確認 → Skills「Commit」
5. 承認が多すぎる → Mode（/permissions）で Auto / Read-only を調整

## 7. 困ったとき

- **キーが効かない（初回）**: システム設定 → プライバシーとセキュリティ → オートメーション で Ulanzi Studio → System Events を許可
- **Accept を押しても何も起きない**: 橙以外ではガードが送出を止めます（正常）。`~/Library/Logs/vibe-deck-plugin.log` に `guard blocked` とあれば仕様どおり
- **`/plan` などが文章として送信されてしまう**: チャット入力欄以外にフォーカスがある状態でした。Focus を押してから再実行してください
- **色が更新されない**: Page 3 の Refresh → `curl http://127.0.0.1:17823/health`
