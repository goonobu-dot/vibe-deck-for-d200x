# Vibe Deck 操作ガイド — Codex 編

対象プロファイル: **Codex_D200X**（テーマ色: 黒＋ティール）
対象アプリ: **ChatGPT.app（デスクトップ）** — Codex の操作キーはデスクトップアプリ前提です

## 1. 画面の見かた

### 上段5キー = エージェントレーン（全ページ共通・動的カード）

Codex エージェント最大5つが**全面1色のカード**（状態色＋白抜き文字）で並びます。カードには**状態ラベル・経過時間・スレッド名**、橙のときは**承認内容**が表示されます。**カードの名前はスレッド名**です — 無名のスレッドは開始日時（例 `7/31 10:19`）になり、スレッドに名前を付けるとその名前が表示されます。起動時は左から順に点灯します。

| 色 | 意味 | あなたがやること |
|----|------|------------------|
| 白 Idle | 待機中 | 指示を出す（New / Skills） |
| 青 Thinking | 作業中（呼吸アニメ。15分超で呼吸が約2倍速の長考アラート） | 待つ（止めたければ Stop） |
| 緑 Done | ターン完了直後（白チェックがポップ） | Diff（Review）で確認 |
| 深緑 Done | **未確認の完了**（90秒後から最大30分保持） | レーンを押して既読に（白へ戻る） |
| 橙 Input | **承認待ちオーバーレイ表示中**（カード点滅・Accept キーもオレンジ点滅） | Accept / Reject |
| 赤 Error | エラー | レーンを押して画面確認 |
| 灰 Ready | 空きレーン | 押すと ChatGPT を前面化 |
| 濃灰 OFFLINE | bridge 不達（3回連続失敗で全レーン表示・自動復帰） | ブリッジを確認 |

レーンを押すと**既読化＋ ChatGPT.app の前面化**が行われます。3段目右端の細長い表示は本体の小窓ウィジェット（時計）で、キーではありません。**ページ移動は下段の物理ボタン左右**です。

## 2. Page 1 — CONTROL（このキーで実際に起きること）

| キー | 表示 | Codex での実動作 |
|------|------|------------------|
| 中段1 | Accept | `a` 送信（**Accept once＝一度だけ許可**。橙のときだけ発火） |
| 中段2 | Reject | `d` 送信（**Decline＝否認**。橙のときだけ発火） |
| 中段3 | Stop | Esc 送信（ターン中断。青/橙のときだけ発火） |
| 中段4 | Diff | ⌘⌥B（Review パネルの開閉） |
| 中段5 | New | ⌘N（新規チャット） |
| 下段1 | Voice | ⌃⇧D（音声入力） |
| 下段2 | Terminal | ⌃`（ターミナル開閉） |
| 下段3 | Mode | チャット欄に `/permissions` を入力して実行（権限設定を開く） |

どのキーも押すと**自動で ChatGPT.app を前面化→前面確認→送出**します。

**Codex 固有の注意**:
- `a` / `d` は**承認オーバーレイが表示されている間だけ**意味を持つキーです。それ以外のタイミングだと文字入力になってしまうため、デッキ側のガードが「橙のときだけ送出」に制限しています。これが誤爆防止の要です。ガードに阻止された押下は**警告音＋押したキーの赤フラッシュ**で知らせます。
- Accept は「一度だけ許可」です。セッション全体を許可したい場合は画面上で `s`（session）を選ぶか、Mode（/permissions）で恒久設定を変えてください。
- Mode キーはチャット入力欄にフォーカスがある状態で効きます（自動前面化後、入力欄が選ばれていない場合は一度クリックが必要なことがあります）。

## 3. Page 2 — SKILLS（定型プロンプト8）

押すとチャット入力欄にプロンプト冒頭が入力されます（**送信はされません**。続きを書いて Return）。

中段: Plan / Implement / Review / Fix / Test
下段: Explain / Commit / Summary

## 4. Page 3 — SYSTEM

共通行（中段）: Tool（押すたびツール切替）/ Refresh（状態色の再取得）/ Settings（⌘,）/ Help（⇧⌘/）/ **Model（⇧⌘P コマンドメニュー）**

**Codex 固有ゾーン（下段3キー）**:

| キー | 動作 |
|------|------|
| Plan | `/plan` を入力して実行（計画モード＝深く考えてから着手） |
| Fast | `/fast` を入力して実行（高速モード＝軽いタスク向け） |
| Quick | ⌘⌥N（クイックチャット） |

## 4.5 Page 4 — COMMANDS（自走コマンド）

中段の5キーは全ツール共通の「自走プロンプト」です。押すと入力欄に文が入ります（**送信はされません**。Goal は続きにゴールを書いて Return、他は必要なら補足してから Return）。

| キー | 動作 |
|------|------|
| Goal | 「ゴール: 次の状態になるまで自走で完了させてください → 」を入力（続きにゴール条件を書く） |
| Continue | 「続きを完了まで進めてください。途中で止まらず、詰まったら状況を報告してください。」を入力 |
| FixAll | 「残っているエラー・警告・テスト失敗をすべて修正してください。」を入力 |
| TestAll | 「テストを追加・実行し、全部通るまで修正を繰り返してください。」を入力 |
| Ship | 「変更をセルフレビューして、コミットメッセージを付けてコミットまで仕上げてください。」を入力 |

**Codex 固有ゾーン（下段3キー）**:

| キー | 動作 |
|------|------|
| Goal | `/goal ` を入力（**送信はされません。ゴールを入力して Return**） |
| History | ⌘G（過去チャット検索） |
| Panel | ⌘J（パネル開閉） |

## 5. ダイヤル（全ページ共通）

| ダイヤル | 回転 | 押し込み |
|----------|------|----------|
| 左 | スクロール（左=下 / 右=上） | — |
| 中 | チャット移動（⌘[ / ⌘]） | ⌘G（過去チャット検索） |
| 右 | **メニュー選択ジョグ**（開いているメニュー内を ↑/↓ で移動） | **Return（確定）** |

**メニューの切替手順**: Page 1 の Mode キー（または Page 3 の Effort / Model キー）でメニューを開く → 右ダイヤルを回して選ぶ → 右ダイヤルを押して確定。Effort / Model キーは単独でも「押すたび1段切替」します。

**ツール切替は Page 3 の Tool キー**です。押すたび Claude→Codex→Cursor と巡回し、Studio が自動再起動して切り替わります（約9秒・数秒消灯は正常）。/plan・/fast のワンタッチ実行は Page 3 の Plan / Fast キーを使ってください。

## 6. おすすめワークフロー

1. 白 → Skills「Plan」で計画 → 内容を確認して実装指示
2. 青 → 放置。急ぎなら Page 3 の Fast キー（/fast）
3. **橙 → Accept（一度だけ許可）/ Reject**
4. 緑 → Diff（Review パネル）で差分確認 → Skills「Commit」
5. 承認が多すぎる → Mode（/permissions）で Auto / Read-only を調整

## 7. 困ったとき

- **キーが効かない（初回）**: システム設定 → プライバシーとセキュリティ → オートメーション で Ulanzi Studio → System Events を許可
- **Accept を押したら警告音が鳴ってキーが赤くフラッシュした**: 橙以外ではガードが送出を止め、音とフラッシュで知らせます（正常）。`~/Library/Logs/vibe-deck-plugin.log` に `guard blocked` とあれば仕様どおり
- **レーンに日時が表示される**: 無名スレッドの仕様です。Codex 側でスレッドに名前を付けると、カードにその名前が表示されます
- **`/plan` などが文章として送信されてしまう**: チャット入力欄以外にフォーカスがある状態でした。上段レーンを押して ChatGPT を前面化し、入力欄をクリックしてから再実行してください
- **色が更新されない**: Page 3 の Refresh → `curl http://127.0.0.1:17823/health`
